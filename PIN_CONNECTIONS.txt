1. ARDUINO UNO (Motor Driver, Line Following & Obstacle Sensor)
--------------------------------------------------------------------------------

[TB6612FNG Motor Driver]
  * PWMA  -------> Arduino Uno Pin D5  (PWM speed control Motor A)
  * AIN1  -------> Arduino Uno Pin D3  (Direction 1 Motor A)
  * AIN2  -------> Arduino Uno Pin D2  (Direction 2 Motor A)
  * PWMB  -------> Arduino Uno Pin D6  (PWM speed control Motor B)
  * BIN1  -------> Arduino Uno Pin D4  (Direction 1 Motor B)
  * BIN2  -------> Arduino Uno Pin D7  (Direction 2 Motor B)
  * STBY  -------> 5V (Hardwired directly to 5V to enable driver)
  * VM    -------> Motor Power Source (e.g., 7.4V - 12V Battery)
  * VCC   -------> Arduino 5V
  * GND   -------> Arduino GND (Common Ground with Battery)

[HC-SR04 Ultrasonic Sensor (Obstacle / Person Detection)]
  * VCC   -------> Arduino 5V
  * TRIG  -------> Arduino Uno Pin D8
  * ECHO  -------> Arduino Uno Pin D9
  * GND   -------> Arduino GND

[5-Channel Analog Line Tracking Sensor Array]
  * VCC   -------> Arduino 5V
  * GND   -------> Arduino GND
  * OUT 1 -------> Arduino Uno Pin A0 (Far Left)
  * OUT 2 -------> Arduino Uno Pin A1 (Mid Left)
  * OUT 3 -------> Arduino Uno Pin A2 (Center)
  * OUT 4 -------> Arduino Uno Pin A3 (Mid Right)
  * OUT 5 -------> Arduino Uno Pin A4 (Far Right)
  * (NOTE: 1 = BLACK above THRESHOLD 850, 0 = WHITE below THRESHOLD 850.
     All-black station zone / T-junction / Crossline: S1 && S2 && S3 && S4 && S5 all > 850 -> AUTO-STOP)

[Dedicated Serial Connection to Unit 1 (ESP32-C3) or Unit 2 (NodeMCU ESP8266)]
  * Unit 1 Robot (ESP32-C3):
      - Arduino Pin D11 (ESP_TX_PIN) ------> ESP32-C3 GPIO 2 (UNO_RX)
      - Arduino Pin D10 (ESP_RX_PIN) <------ ESP32-C3 GPIO 3 (UNO_TX)
      - Arduino GND                  <------> ESP32-C3 GND (CRITICAL: Common Ground!)
  * Unit 2 Robot (NodeMCU ESP8266):
      - Arduino Pin D11 (ESP_TX_PIN) ------> NodeMCU Pin D5 / GPIO 14 (UNO_RX) [Use 1k:2k divider if 5V]
      - Arduino Pin D10 (ESP_RX_PIN) <------ NodeMCU Pin D7 / GPIO 13 (UNO_TX)
      - Arduino GND                  <------> NodeMCU GND (CRITICAL: Common Ground!)
  * (Pins D0 and D1 on Arduino Uno and USB TX/RX on NodeMCU remain 100% free for USB Serial Monitor & flashing)

4. CONTROLLED GRADUAL SERVO TILT (PIN 19 / PIN D3), OPEN LID FIRST & REVERSE RETURN
--------------------------------------------------------------------------------
  * Upright Reference: 45 degrees
  * Dump Target: 180 degrees
  * Careful & Controlled Servo Motion:
    - Gradual 1-degree steps with 25ms delay (takes ~3.4s for 135-degree stroke to prevent mechanical stress).
    - Prevents sudden mechanical shock or biohazard splashing.
    - Step delay configurable from 15ms to 30ms via web UI.
  * Discrete Control 5-Sensor Line Follower:
    - Threshold: 850 (1 = BLACK above threshold, 0 = WHITE below threshold).
    - Priority Rules:
      * Finish Line / All-Black Station: S1 && S2 && S3 && S4 && S5 -> AUTO-STOP.
      * Extreme Left ((S1 && S2) || S1): Sharp Left (Left: -40, Right: 200, lastDirection = -1).
      * Extreme Right ((S4 && S5) || S5): Sharp Right (Left: 200, Right: -40, lastDirection = 1).
      * Mild Left ((S2 && S3) || S2): Mild Left (Left: 200, Right: 255, lastDirection = -1).
      * Mild Right ((S3 && S4) || S4): Mild Right (Left: 255, Right: 200, lastDirection = 1).
      * Center (S3): Straight (Left: 255, Right: 255).
      * Line Lost (00000): Re-acquire line by spinning in last known direction.
  * Direct Forward-and-Reverse Disposal Sequence:
    1) Moving to Disposal: Robot starts at Initial Station and follows line FORWARD.
    2) Disposal Detection: When ALL 5 sensors detect black, the robot STOPS immediately.
       Uno signals ARRIVED_DISPOSAL.
    3) Open Lid First: Controller engages the lid servo to 90 degrees and waits 700ms so the
       lid is fully open before the bin tilts.
    4) Gradual Tilt 3x: Tilt servo sweeps smoothly from 45 degrees to 180 degrees (25ms/deg),
       holds at 180 degrees for calibrated dump duration, returns gradually to 45 degrees,
       and repeats for 3 full cycles.
    5) Close Lid: Tilt servo returns to 45 degrees upright, and the lid servo closes shut (0 degrees).
    6) Backward Return: Controller instructs Uno RETURN_TO_BASE. Uno runs BACKWARD along the line.
    7) Base Detection: When ALL 5 sensors detect black at the Initial Station, the robot STOPS in IDLE.
       The robot is already parked facing forward, ready for the next disposal cycle!

--------------------------------------------------------------------------------
5. HANDS-FREE PROXIMITY LID OPENING & FULL BIN LOCKING SPECIFICATION
--------------------------------------------------------------------------------
  * Idle / Parked Mode (Stationary at Base, Not Running, Not Disposing):
    - Front Ultrasonic Sensor (Arduino Pins D8/D9) functions as a touchless proximity sensor.
    - When a person approaches (distance < 50 cm threshold), Uno signals OPEN_LID over
      dedicated UART (D10/D11) to the controller.
    - Controller engages the lid servo to 90 degrees for the calibrated hold duration (default 5000 ms),
      then closes smoothly.
  * Active Running / Disposing Mode:
    - While moving, spinning, or dumping, the front ultrasonic sensor acts exclusively as an
      emergency obstacle avoidance sensor and hands-free lid opening is disabled.
  * Full Bin Overflow Prevention (Lockout):
    - When waste depth reaches the Full threshold (default <= 10 cm), the controller sends
      "BIN_FULL,1" to the Arduino Uno, locking the lid shut until a disposal cycle completes.
